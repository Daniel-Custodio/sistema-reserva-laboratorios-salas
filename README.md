# Sistema de Reserva de Laboratórios e Salas de Aula

Projeto de Prática Profissional — 2º semestre.

## Integrante

- Daniel de Padua Custodio — RA: 26552

## Objetivo

Desenvolver um sistema web para cadastro e reserva de laboratórios
e salas de aula.

## Tecnologias utilizadas

- Node.js;
- React;
- Next.js;
- SQL Server;
- GitHub.

## Funcionalidades

- Cadastro de usuários;
- Cadastro de laboratórios;
- Cadastro de salas;
- Cadastro de status;
- Login de acesso;
- Reserva de laboratórios e salas;
- Consulta de reservas.
